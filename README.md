# Mambo-Naval---Trabalho-de-CODING-para-PYTHON
Projeto de jogo Batalha Naval, tematizado, ao melhor de nossas habilidades tendo em mente limitações de software e de requisitos, em torno da personagem fictícia Matikanetanhauser, vulgo, Mambo 

O programa deve ser executado em Python. O jogo é uma batalha naval, onde cada jogador possui 11 navios posicionados em uma matriz 5x5. O objetivo é acertar os navios do adversário lançando Mambo mísseis em coordenadas específicas. Cada acerto vale 9 pontos, e o jogo pode ser jogado no modo 'Melhor de 3' ou 'Melhor de 5'. O jogador que acumular mais pontos ao final das rodadas vence a partida.

Passo a passo para rodar o jogo:

1. Instalação do Python: Acessar o site oficial https://www.python.org/downloads/ e baixar uma versão do Python 3. Durante a instalação, marcar a opção "Add Python to PATH" e concluir o processo.

2. Preparação do arquivo: Salvar o código-fonte do Mambo Naval em um arquivo chamado `mambo_naval.py`, utilizando um editor de texto ou ambiente de desenvolvimento.

3. Abertura do terminal: Abrir o Prompt de Comando (CMD) do Windows.

4. Localização do arquivo: Utilizar o comando `cd` para acessar a pasta onde o arquivo `mambo_naval.py` foi salvo.

5. Execução do programa: Digitar o comando abaixo no terminal e pressionar Enter.

python MAMBO_NAVIOS_V7.py
