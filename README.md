# Mambo-Naval---Trabalho-de-CODING-para-PYTHON
Projeto de jogo Batalha Naval, tematizado, ao melhor de nossas habilidades tendo em mente limitações de software e de requisitos, em torno da personagem fictícia Matikanetanhauser, vulgo, Mambo 

O programa deve ser executado no VS.Code utilizando o Python. O jogo é uma batalha naval, onde cada jogador possui 11 navios posicionados em uma matriz 5x5. O objetivo é acertar os navios do adversário lançando Mambo mísseis em coordenadas específicas. Cada acerto vale 9 pontos, e o jogo pode ser jogado no modo 'Melhor de 3' ou 'Melhor de 5'. O jogador que acumular mais pontos ao final das rodadas vence a partida.
